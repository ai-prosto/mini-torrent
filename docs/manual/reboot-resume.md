# Ручная проверка BEH-10: после перезагрузки закачки возобновляются без команды

Проверяет FR-04/1: демон регистрирует себя в автозапуске ОС при первом
старте (D-08) — LaunchAgent `~/Library/LaunchAgents/dev.mt.daemon.plist`
с `RunAtLoad` на macOS, user-unit `~/.config/systemd/user/mt.service` с
`WantedBy=default.target` плюс `loginctl enable-linger` на Linux — и на
каждом старте сам поднимает записи со статусом `downloading` из сохранённого
metainfo (D-07). Пользователь после перезагрузки ничего не вводит.

## Подготовка

На проверяемой машине (macOS или Linux):

```sh
uv sync            # или установить пакет: uv pip install .
```

Понадобится крупный недокачиваемый торрент (например, образ дистрибутива),
чтобы закачка заведомо не успела завершиться до перезагрузки.

## Шаги

1. **Старт и регистрация.** Выполнить `uv run mt add <magnet>` — демон
   поднимется сам (BEH-08). Убедиться, что автозапуск зарегистрировался:
   - macOS: `plutil -p ~/Library/LaunchAgents/dev.mt.daemon.plist` —
     в выводе `RunAtLoad => 1` и команда запуска `... -m mt daemon`;
   - Linux: `systemctl --user is-enabled mt.service` печатает `enabled`,
     `loginctl show-user $USER -p Linger` печатает `Linger=yes`.

2. **Недокачанная закачка.** `uv run mt` — у закачки статус `downloading`
   и процент меньше 100. Запомнить процент.

3. **Перезагрузка.** Перезагрузить машину. После загрузки войти в систему
   (macOS: LaunchAgent стартует при входе; Linux: unit стартует и без входа
   благодаря linger). Никаких команд `mt` не вводить.

4. **Возобновление.** Подождать около минуты и выполнить только
   `uv run mt` (просмотр — не управление). Ожидание:
   - демон уже работает: `ls ~/.local/state/mt/mt.sock` существует,
     pid в `~/.local/state/mt/mt.lock` — живой процесс;
   - закачка в списке со статусом `downloading`, процент не ниже
     запомненного (BEH-11) и со временем растёт.

## Критерий зелёности

После перезагрузки демон запущен средствами платформы, недокачанная
закачка снова качается, и для этого не было введено ни одной команды.
