## Цели

### G-01: Качать торренты из терминала без возни с настройками
Готовые клиенты слишком тяжёлые. Нужен лёгкий CLI: закинул ссылку — и дальше оно само, без конфигурирования перед первым запуском.

### G-02: Закачка живёт отдельно от терминала
Закрыл терминал, вышел из ssh, перезагрузил машину — скачивание продолжается с того же места, ничего не теряется и не начинается заново.

### G-03: Видеть в одном окне, что происходит
Открыл TUI — сразу видно все текущие закачки с прогрессом и то, что уже скачано. Список отражает реальность на диске.

## Функции

### FR-01: Добавление закачки командой
**Цели:** G-01
**Критерии приёмки:**
- `mt add <magnet>` добавляет закачку и завершается с кодом 0, закачка появляется в списке демона
- `mt add <файл.torrent>` добавляет закачку из локального .torrent-файла
- Добавление работает без предварительного конфига: при пустом конфиге файлы кладутся в папку по умолчанию
**Слова владельца:** и то, и другое; без лишних настроек, закинул ссылку и он качает

### FR-02: Все закачки идут параллельно
**Цели:** G-01, G-03
**Критерии приёмки:**
- После добавления трёх ссылок подряд все три имеют статус «качается» одновременно, без очереди
- В TUI они видны тремя строками списка
**Слова владельца:** все сразу, списком

### FR-03: Фоновый демон
**Цели:** G-02
**Критерии приёмки:**
- После закрытия терминала (или разрыва ssh-сессии) процесс демона жив и прогресс закачки продолжает расти
- Демон поднимается сам при первой команде `mt add`, отдельного запуска вручную не требуется
**Слова владельца:** работает как демон, при закрытии терминала продолжает работать

### FR-04: Возобновление после перезапуска
**Цели:** G-02
**Критерии приёмки:**
- После kill демона и перезагрузки машины незавершённые закачки возобновляются автоматически, без команды пользователя
- Процент уже скачанного после возобновления не меньше, чем был до остановки (данные не качаются заново)
**Слова владельца:** продолжает с места, сам после старта

### FR-05: TUI со списком закачек и скачанного
**Цели:** G-03
**Критерии приёмки:**
- `mt` (или `mt tui`) открывает окно со списком: имя, процент, скорость для идущих закачек
- В том же списке видны уже скачанные файлы
- Прогресс в окне обновляется сам, без нажатий
**Слова владельца:** для статуса TUI; смотрю и прогресс и закачанные файлы

### FR-06: Удалённый с диска файл уходит из списка
**Цели:** G-03
**Критерии приёмки:**
- Если удалить скачанный файл из папки загрузок, запись о нём пропадает из TUI и из состояния демона
- Пропажа происходит без перезапуска демона
**Слова владельца:** если файл удалить, то он перестает отобржаться, удаляется из закачек

### FR-07: После скачивания раздача прекращается
**Цели:** G-01
**Критерии приёмки:**
- При достижении 100% закачка переходит в «готово» и соединения с пирами закрываются
- Исходящий трафик по этому торренту после завершения — ноль
**Слова владельца:** скачал и всё, раздачу не держим

### FR-08: Папка загрузок в конфиге
**Цели:** G-01
**Критерии приёмки:**
- Без конфига файлы попадают в папку по умолчанию (например, ~/Downloads)
- Если в конфиге задан путь — новые закачки сохраняются туда
**Слова владельца:** одна папка, но её можно задать в конфиге

### FR-09: Работает на macOS и Linux
**Цели:** G-01, G-02
**Критерии приёмки:**
- Один и тот же набор команд (`add`, TUI) отрабатывает и на macOS, и на Linux
- Демон переживает отключение ssh-сессии на Linux-машине
**Слова владельца:** и там, и там

## Контекст

- Пользователи: только я
- Авторизация: нет
- Сеть: есть — интернет, торрент-сеть (DHT, трекеры, пиры)
- Локальная система: читает .torrent-файлы и файл конфига; пишет скачанное в папку загрузок и состояние закачек, чтобы возобновляться после перезапуска; следит за наличием скачанных файлов на диске
- Платформа: macOS и Linux
- Прочее: Добавление — только командой в терминале, из TUI не добавляем. TUI — только просмотр.
